# S4A Brand Foundation

Build Phase 1 only for S4A Auto Repair & Maintenance Services: a premium, responsive frontend foundation and reusable design system. Use the supplied official logo unchanged as the brand reference. Do not add backend, database, auth, payments, external APIs, or build complete future page experiences. Implement the specified black/white/red brand system, accessible responsive global header/nav (Home, About, Services, S4A Consult, IT/SIWES, Gallery, Contact), Book a Repair primary CTA, IT/SIWES secondary CTA, mobile menu, containers/grids/spacing, footer with confirmed contact info, and reusable buttons, form controls, cards, section headings, badges, dialog, and state patterns. Use confirmed taglines. Ensure a refined automotive, trustworthy, non-template visual design, strong mobile behavior, semantic HTML, focus states, contrast, reduced-motion support, and logical component architecture for later phases.
